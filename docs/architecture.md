# 아키텍처: "활동지" 흐름

## 동작

1. 메인 대화창에 `활동지`라고 입력하면 활동지 화면(Artifact)이 열린다.
2. 명단 1번 아이부터 "오늘 '앤디'의 하루는 어땠나요?"를 보여 준다.
3. 입력창에 키워드나 문장으로 적고 `일지 작성`을 누르면 7줄 정도의 교사 말투 일지가 나온다.
4. `건너뛰기`로 결석이나 나중에 쓸 아이를 넘길 수 있다. 상단 아이 이름을 누르면 순서와 관계없이 바로 이동한다.
5. 결과는 화면에서 고칠 수 있고 `복사` 버튼으로 복사한다.
6. 상단 `한 번에` 탭에서는 모든 아이의 키워드를 한 화면에 적고 버튼 한 번으로 전체 일지를 작성한다. 비운 아이는 건너뛴다.
7. `완료`를 누르면 아이별로 정리한 전체 목록이 나오고, `전체 복사`로 복사한다.

## 구성

| 구성 요소 | 역할 |
|---|---|
| 프로젝트 지침 (INSTRUCTIONS.md) | `활동지` 트리거를 인식해 화면을 열고, 화면을 쓸 수 없으면 대화창에서 같은 순서로 진행 |
| 활동지 화면 (app/activity-log.html) | 명단 순서, 건너뛰기, 입력창, 일지 생성(Claude 호출), 복사, 완료 정리 |
| Knowledge (knowledge/) | 명단, 말투 예시, 작성 규칙 |

## 상태 저장

진행 상황(작성/건너뜀, 키워드, 결과)은 그날 날짜 기준으로 브라우저에 저장된다. 같은 브라우저에서 다시 열면 이어서 쓸 수 있다.

## 한계

- 클립보드 자동 복사는 불가능해서 복사 버튼 한 번으로 끝나는 구조로 만들었다.
- 화면에서 자동 작성이 막힌 경우에는 키워드만 모아 두었다가, 완료 시 정리본을 대화창에 붙여 넣으면 Claude가 아이별 일지로 작성한다.
- 명단은 현재 화면 코드와 `knowledge/01-roster.md` 두 곳에 있으므로, 명단을 바꾸면 둘 다 고쳐야 한다.
- 말투는 임시로 정했고, 예시를 받으면 `knowledge/02-tone-samples.md`와 화면의 작성 지침에 반영한다.
