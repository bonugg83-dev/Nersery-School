# 아키텍처: "활동지" 흐름

## 동작

1. 메인 대화창에 `활동지`라고 입력하면 활동지 화면(Artifact)이 열린다.
2. 명단 1번 아이부터 "오늘 '앤디'의 하루는 어땠나요?"를 한 명씩 보여 준다.
3. 키워드나 문장을 입력하고 `다음 아이`를 누르면 입력만 저장되고 다음 아이로 넘어간다. 이 단계에서는 일지를 만들지 않는다.
4. `건너뛰기`로 결석한 아이를 넘길 수 있고, 상단 아이 이름을 누르면 순서와 관계없이 바로 이동한다.
5. 하단 `N명 한 번에 작성` 버튼을 누르면 입력한 아이들의 7줄 일지를 한꺼번에 만든다. 적지 않은 아이는 자동으로 건너뛴다.
6. 결과는 아이별로 정리되어 나오고 아이별 카드의 `복사` 버튼으로 한 명씩, 또는 `전체 복사`로 복사한다. `돌아가서 수정`에서 키워드를 고치면 바뀐 아이만 다시 작성한다.

## 명단 관리

- 화면 위쪽 `명단 관리`에서 아이를 직접 추가·삭제하고 이름, 나이, 성별을 고친다. 삭제는 두 번 눌러야 지워진다.
- 목록을 여러 개 만들 수 있다. 첫 목록은 `1번 목록`(임시 명부)이고, `+ 새 목록`으로 빈 목록을 더한다. 목록 이름은 직접 바꾼다.
- 목록마다 오늘 작성 내용(키워드, 건너뜀, 결과)이 따로 저장된다.
- 명단은 브라우저에 저장되므로 같은 브라우저에서만 유지된다. 다른 기기에서는 다시 입력해야 한다.

## 구성

| 구성 요소 | 역할 |
|---|---|
| 프로젝트 지침 (INSTRUCTIONS.md) | `활동지` 트리거를 인식해 화면을 열고, 화면을 쓸 수 없으면 대화창에서 같은 순서로 진행 |
| 활동지 화면 (app/activity-log.html) | 명단 순서, 건너뛰기, 입력창, 일지 생성(Claude 호출), 복사, 완료 정리 |
| Knowledge (knowledge/) | 명단, 말투 예시, 작성 규칙 |

## 상태 저장

진행 상황(작성/건너뜀, 키워드, 결과)은 그날 날짜 기준으로 브라우저에 저장된다. 같은 브라우저에서 다시 열면 이어서 쓸 수 있다.

## 한계

- 클립보드 자동 복사는 불가능해서 복사 버튼 한 번으로 끝나는 구조로 만들었다.
- 화면에서 자동 작성이 막힌 경우에는 키워드만 모아 두었다가, 완료 시 정리본을 대화창에 붙여 넣으면 Claude가 아이별 일지로 작성한다.
- 화면의 명단은 브라우저에 저장되고, `knowledge/01-roster.md`는 대화창 방식용 별도 사본이다. 둘은 자동으로 맞춰지지 않는다.
- 말투는 임시로 정했고, 예시를 받으면 `knowledge/02-tone-samples.md`와 화면의 작성 지침에 반영한다.
